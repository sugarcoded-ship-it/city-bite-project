> **Correction (2026-07-09):** Removed the "real-time location of my delivery on a map" story and reworded the two delivery hand-off stories below — the shipped design has no map or location tracking of any kind, and delivery hand-off is a self-claim (any staff member can claim an in-preparation order), not a manager assigning a colleague. See ADR 002-E.

| Role | User Story | Why it Matters | Core / Optional |
| :--- | :--- | :--- | :--- |
| Customer | As a customer, I want to see the menu grouped by category and see available items at the top so that I can easily find what I want to order. | A clear menu helps customers make quick decisions and reduces frustration. | Core |
| Customer | As a customer, I want to customize my order with options (e.g., no spice, add fried egg) so that I can get my food prepared to my liking. | Customization enhances customer satisfaction and can increase order value. | Core |
| Customer | As a customer, I want to see real-time status of my order so that I can plan accordingly. | Real-time updates improve customer experience and reduce anxiety about order status. | Core |
| Customer | As a customer, I want to see an estimated ready/arrival time (ETA) for my order so that I know roughly when to expect it without guessing. | Removes the "how much longer" follow-up call and sets clear expectations. | Core |
| Customer | As a customer, I want to see when the store is open or closed so that I can only place orders during business hours. | Clear operating hours prevent customer frustration and reduce invalid orders. | Core |
| Customer | As a customer, I want to be able to choose from a variety of payment options (e.g., credit card, cash on delivery) so that I can pay in the way that is most convenient for me. | Customers want a faster and more familiar way to pay for their orders. | Optional |
| Staff | As a staff member, I want to view all incoming orders in a queue so that I can manage them efficiently. | A clear order queue helps staff manage workload and ensures timely preparation. | Core |
| Staff | As a staff member, I want to quickly update the status of menu availability and order progress so that customers have accurate information. | Accurate status updates reduce customer frustration and improve trust in the system. | Core |
| Staff | As a staff member, I want to see summarized customer orders with special requests highlighted so that I can reduce errors and ensure customer satisfaction. | Clear order details help staff prepare orders correctly and reduce mistakes. | Core |
| Staff | As a staff member, I want to manage the restaurant's stock inventory (add, adjust, and categorize items) so that ingredient availability is always up to date. | Accurate stock tracking allows staff to mark unavailable items before customers try to order them. | Core |
| Owner | As an owner, I want to see a dashboard overview of today's orders, active staff count, and store open/closed status so that I can quickly understand the restaurant's operational state without checking each section individually. | A single overview screen reduces the time the owner spends gathering information and highlights anything that needs immediate attention. | Core |
| Owner | As an owner, I want to add, edit, and delete menu items (including name, price, category, description, image, and ingredients) so that the menu displayed to customers always reflects what the restaurant actually offers. | Keeping the menu accurate prevents customers from ordering items that have changed in price or are no longer available. | Core |
| Owner | As an owner, I want to activate or deactivate individual menu items so that items that are temporarily unavailable are hidden from customers without permanently deleting them. | Deactivating an item is faster and safer than deleting it, and allows reactivation when the item becomes available again. | Core |
| Owner | As an owner, I want to see which ingredients are insufficient when a menu item is marked as out of stock so that I can quickly identify what needs to be restocked. | Knowing exactly which ingredient is short saves time compared to manually checking stock levels one by one. | Core |
| Owner | As an owner, I want to view a list of all staff members with their active or inactive status so that I can see who is currently able to log in and work. | A clear staff list makes it easy to confirm who is active and spot any accounts that should be disabled. | Core |
| Owner | As an owner, I want to activate or deactivate staff accounts so that only current employees have access to the staff dashboard. | Disabling a departed employee's account immediately prevents unauthorized access to the system. | Core |
| Owner | As an owner, I want to view an individual staff member's details (full name, email, phone, address, salary, and leave day allowance) so that I have a complete record of each employee in one place. | Having all staff details in the system reduces the need to maintain a separate spreadsheet and makes HR information accessible when needed. | Core |
| Owner | As an owner, I want to control the store's open or closed status so that customers cannot place orders outside of operating hours. | Manual control of the store state gives the owner flexibility to open late, close early, or pause orders for operational reasons without changing business hours in a configuration file. | Core |
| Owner | As an owner, I want to view revenue, order volume, and performance analytics so that I can make informed decisions about the menu and staffing. | Data-driven insights help the owner identify top-selling items, peak hours, and trends over time. | Optional |
| Owner | As an owner, I want to review and approve staff day-off requests so that I can manage scheduling and ensure the restaurant is adequately staffed. | Approving leave through the system gives the owner a clear record of who is absent and when, reducing scheduling conflicts. | Optional |
| Staff | As a staff member, I want to cancel an in-progress order and automatically restore its deducted stock and credit the customer so that mistaken or unfulfillable orders don't leave stock incorrectly reduced or the customer out of pocket. | Directly addresses the case's recurring "order changed mid-way" and "item unavailable but still requested" complaints without needing a manual reconciliation step. | Core |
| Staff | As a staff member, I want to claim an in-preparation delivery order for myself so that hand-off to delivery is tracked in the same system as preparation. | Keeps the full order lifecycle — including delivery — visible in one place instead of a separate offline hand-off. | Core |
| Staff | As the staff member who claimed a delivery, I want to see the order's pickup and delivery-address details so that I know exactly what to pick up and where to take it. | Reduces mistakes and back-and-forth calls to confirm delivery details. | Core |
| Staff | As the staff member who claimed a delivery, I want to update the order's status to "On Delivery" and "Delivered" so that the customer and the rest of the team both see accurate delivery progress. | Keeps the customer-facing tracking status accurate without needing to relay updates manually. | Core |
| Customer | As a customer, I want to look up my order's status using my reference number and my logged-in account so that I always have a reliable way to check my order, not just while the browser tab is still open. | Keeps tracking consistent with the rest of the customer app, which already requires an account. | Core |
