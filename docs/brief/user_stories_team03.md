| Role | User Story | Why it Matters | Core / Optional |
| :--- | :--- | :--- | :--- |
| Customer | As a customer, I want to see the menu grouped by category and see available items at the top so that I can easily find what I want to order. | A clear menu helps customers make quick decisions and reduces frustration. | Core |
| Customer | As a customer, I want to customize my order with options (e.g., no spice, add fried egg) so that I can get my food prepared to my liking. | Customization enhances customer satisfaction and can increase order value. | Core |
| Customer | As a customer, I want to see real-time status of my order and the estimated time of arrival so that I can plan accordingly. | Real-time updates improve customer experience and reduce anxiety about order status. | Core |
| Customer | As a customer, I want to see when the store is open or closed so that I can only place orders during business hours. | Clear operating hours prevent customer frustration and reduce invalid orders. | Core |
| Customer | As a customer, I want to see the real-time location of my delivery in map so that I can know exactly when my food will arrive. | Real-time delivery tracking enhances customer experience and reduces uncertainty. | Optional |
| Customer | As a customer, I want to be able to choose variety of payment options (e.g., credit card, cash on delivery) so that I can pay in the way that is most convenient for me. | Customers want a possibly faster and more familiar way that they usually pay for other goods or services | Optional |
| Staff | As Staff, I want to view all incoming orders in a queue so that I can manage them efficiently. | A clear order queue helps staff manage workload and ensures timely preparation. | Core |
| Staff | As Staff, I want to quickly update the status of menu availability and order progress so that customers have accurate information. | Accurate status updates reduce customer frustration and improve trust in the system. | Core |
| Staff | As Staff, I want to see summarized customer orders with special requests highlighted so that I can reduce errors and ensure customer satisfaction. | Clear order details help staff prepare orders correctly and reduce mistakes. | Core |
